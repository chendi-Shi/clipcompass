# 结果解读与选型

推荐结果来自固定协议和预算，没有按测试结果重新调参。

## 主结论

- 内容门控没有证明优于LightGCN。Warm NDCG@20为0.18133 vs 0.18105；配对用户bootstrap差值95%区间跨零（[-0.00078, 0.00137]）。Cold NDCG下降到0.24571，差值区间[-0.02836, -0.00059]。
- SSL的cold Recall@20为0.58788±0.00327，高于LightGCN的0.56898；但cold NDCG为0.25800±0.00364，低于0.26035。混合候选NDCG为0.17707，LightGCN为0.17718，不能称全面提升。
- 平滑长观看率这个简单基线的joint NDCG为0.18032，超过所有当前神经模型。验证集选出的神经模型是content_ssl，但测试结果没有证明其为最佳业务选型。
- 图/语义融合明显强于未经训练的E5历史画像（joint NDCG 0.03865），但这个比较不能代替与强协同/曝光率基线的比较。

## 为什么冷启动ID模型也有指标

这些模型的cold列全零，推荐只由平分顺序决定。ID升序和降序的cold NDCG分别为0.26035和0.19709；3seed随机排序约0.222。数据中的ID顺序存在可利用的结构，固定tie-break让结果可复现，却不代表冷启动能力。

SSL语义分支可以对cold内容产生非恒定分数，相比随机排序更好，但没有超过ID升序这个意外强的对照。必须保留两个事实，不能通过替换平分协议制造胜出结论。

## 协议的适用范围

Cold评估914个有正例用户，平均46.07个候选，top20覆盖比例较高；与warm Recall不能直接比较。候选来自已发生的曝光，仍受旧推荐策略影响。Caption是发布快照，无法核验历史时刻版本。标签是长观看代理，噪声、视频长度和重复观看都可能影响它。

模型统一预算并不等于充分超参搜索。门控、SSL的失败属于这组配置与协议，不是方法无效的证明。新实验应将分支校准、SSL权重与更好内容特征作为待验证假设，并建立未被反复使用的测试集。

## 工程选型

保留按验证集选择的content_ssl作为研究模型及服务checkpoint，方便复现既定流程。若实际部署，需要在新的验证协议下与平滑曝光率等基线重新选型，而不是因为模型更复杂就优先采用。

Qwen适配结果在独立LORA_REPORT.md中报告，不能归因为上述推荐变化。

## LLM适配的实测选型

LoRA测试Macro-F1为0.1894，base prompt为0.0367，证明这次适配改善了固定代码分类；但E5线性分类器为0.5590、TF-IDF线性为0.5302。在这组弱标注、小预算文本任务上，应优先考虑线性方案。LoRA使用445条独立训练内容、160更新步、90,112参数、单seed，不能由这一结果推广到更大模型和充分训练。

两种线性基线与LoRA的标注内容相同，输入长度不同：线性方法使用完整发布文本，E5最多128token；Qwen标题取前96字符。这是标注预算对齐的选型对照，不是完全同输入长度的架构实验。
