# 简历项目材料

## 可直接使用的项目描述

**ClipCompass：基于内容语义与协同图的短视频冷启动推荐**  
技术栈：Python / PyTorch / LightGCN / multilingual E5 / Qwen2.5 / PEFT LoRA

- 基于KuaiRec完整small matrix构建推荐研究流程，处理467.7万条真实曝光、1411用户及3327条内容；按首次曝光去重、全局时间划分和314个内容隔离建立冷启动评测，避免测试行为进入训练图。
- 实现BPR-MF、LightGCN与E5语义门控融合，开展图/语义InfoNCE消融；完成9种方法对照、12次神经模型训练及3seed统计，通过逐用户bootstrap和混合候选评测分析融合效果，发现ID平分顺序对冷启动指标的影响。
- 基于Qwen2.5-0.5B-Instruct实施8类内容文本分类LoRA，在最后4层q/v投影训练rank8适配器；实现完整词表回复token监督及冻结前缀/KV缓存，校验完整模型数值一致性和适配器梯度，比较base prompt与同标注预算分类基线。
- 实现可加载checkpoint的全目录向量检索、历史曝光过滤及HTTP推荐接口；3327条内容目录下300次CPU查询p95为1.74ms（不含HTTP/编码器/加载），交付依赖快照、复现命令、实验报告和实际LoRA适配器。

## 如何使用数字

467.7万是原始曝光数；去重后449.5万条，移除cold训练曝光后285.1万条，训练长观看正例13.38万条。不能把这些数全部说成训练正例，也不能写成467.7万条视频。

推荐实验没有证明内容融合优于强基线，简历不写“全面提升”或“显著提升NDCG”。SSL的cold Recall改善伴随NDCG未胜出，不能只摘一个涨幅。

LoRA的测试和性能数值见下方实测补充，强基线结论必须同时保留。

## 与岗位的匹配

推荐与Learning to rank：BPR、协同图、内容冷启动；LLM应用与微调：真实Qwen适配器、Prompt与mask loss；对比学习：图/语义InfoNCE及消融；研究方法：防泄漏、强基线、统计与误差诊断；落地：推理接口与范围明确的性能测量。

当前视频视觉、MLLM、跨语种迁移和线上业务指标没有实验。项目标题不写“多模态大模型视频理解”或“TikTok线上系统”。使用多语种预训练encoder不等于验证了百语种能力。

## 实测补充（2026-10-10，本机CPU）

- LoRA：160步、90,112可训练参数，实际使用445条独立训练内容；64条验证、160条测试。验证选第120步，测试Macro-F1由base的0.0367到0.1894；TF-IDF线性为0.5302，E5线性为0.5590。只写微调实现与对照研究，不宣称LoRA为最佳方案。
- 推荐服务：3327内容、32维、300次查询；单CPU BLAS线程p50=1.153ms、p95=1.738ms，向量占用606,464字节。范围为向量评分、曝光过滤、topk和JSON构建，不含HTTP/encoder/加载，不是百万级服务压测。
- 验证：20项测试通过，包含未来测试标签不改变训练、冷边隔离、缓存数值一致和LoRA梯度检查。
